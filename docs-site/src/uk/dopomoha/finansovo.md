Covey ведуть волонтери та відкритий код, але є постійні витрати, необхідні для підтримання безпечної та доступної платформи.

## На що йдуть кошти?

Ваші пожертви йдуть безпосередньо на операційні витрати:

1. **Плата за BankID** — Безпечний вхід та верифікація користувачів передбачають транзакційні витрати. Це наша найбільша стаття витрат, але критична для функціонування додатку.
2. **Хостинг та інфраструктура** — Сервери, доменні імена та цілодобова доступність.
3. **Codeberg та інструменти** — Ми підтримуємо Codeberg як платформу і можемо потребувати оплати сервісів CI/CD.

## Як ви можете допомогти

Ми працюємо над створенням формальних каналів для пожертв. Незабаром ви зможете підтримати нас через:

- **Swish** — Швидкі разові пожертви.
- **Open Collective** — Повна прозорість — бачте, як витрачається кожна крона.
- **Codeberg / GitHub Sponsors** — Щомісячна підтримка для довгострокового розвитку.
