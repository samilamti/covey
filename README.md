# Medborgarstöd (CitizenAid) 🇸🇪

Detta är ett öppen källkod-initiativ för att skapa en trygg community där medborgare kan stödja varandra.

## Struktur
- `app/`: Själva mobilapplikationen (HTML/JS/CSS).
- `docs/`: Projektplan, artiklar och regelverk.

## Hur man testar lokalt
För att köra applikationen lokalt på din maskin:

1. Se till att du har [Node.js](https://nodejs.org/) installerat.
2. Öppna en terminal i rotkatalogen.
3. Kör följande kommando:
   ```bash
   npm start
   ```
4. Appen kommer nu vara tillgänglig på en lokal adress (vanligtvis `http://localhost:3000`).

## Dokumentation
Läs mer om projektet i mappen `docs/`.
Varje kodfil i `app/` har också en tillhörande `.md`-fil som förklarar dess tekniska syfte och optimeringar.
