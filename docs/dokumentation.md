# Projektplan: Medborgarstöd (CitizenAid)

## 1. Vision
Att skapa en trygg, oberoende och decentraliserad plattform där medborgare kan hjälpa varandra i vardagen, verifierat med nationell e-legitimation (t.ex. BankID).

## 2. Mål
- **Säkerhet:** Alla användare är verifierade individer.
- **Integritet:** Ingen dataförsäljning, ingen spårning i reklamsyfte.
- **Öppenhet:** Fullt transparent källkod (Open Source).
- **Tillgänglighet:** Fungerar på allt från gamla Android-enheter till nya iPhones.

## 3. Huvudfunktioner
- **Verifierad inloggning:** Integration med BankID/Vipps.
- **Hjälpförfrågningar:** Användare kan be om hjälp med vardagssysslor.
- **Trygghetscommunity:** Lokala grupper för samverkan.
- **Icke-vinstdrivande:** Drivs som ett gemensamt medborgarinitiativ.

## 4. Tidsplan
- **Fas 1:** Prototyp och byggsystem (Nuvarande).
- **Fas 2:** Integration av e-legitimation (Mockup för demo).
- **Fas 3:** Betatestning i begränsat område.
- **Fas 4:** Offentlig lansering.

## 5. Teknisk Stack
- **Frontend:** Ren HTML/JavaScript (fokus på prestanda).
- **Backend:** Node.js (förutsatt för API:er).
- **Bas:** Web-first för maximal räckvidd.

# Artikel: Varför ett medborgarinitiativ är viktigare än Facebook

I en värld där sociala medier har blivit synonyma med datainsamling och vinstoptimering, behövs ett alternativ. Här är skillnaden mellan Medborgarstöd och jättar som Facebook och LinkedIn:

### 1. Du är inte produkten
Facebook tjänar pengar på att sälja din uppmärksamhet till annonsörer. Vi tjänar inga pengar. Vårt enda mål är att du ska få hjälp eller kunna hjälpa någon annan.

### 2. Verifierad identitet kontra anonymitet/botar
Genom att använda nationellt ID (BankID/Vipps) eliminerar vi trollkonton och bedrägerier. Du vet att personen du pratar med är den de utger sig för att vara.

### 3. Öppen källkod (Open Source)
Vår kod är öppen för granskning. Vem som helst kan se hur vi hanterar data. Det finns inga dolda algoritmer som styr vad du ser.

### 4. Icke-vinstdrivande foundation
Vi ägs inte av riskkapitalister. Vi styrs av våra medlemmar och vårt syfte. Syftet är social nytta, inte ekonomisk tillväxt.

# Regelverk för deltagande i Open Source-projektet

För att skapa en välkomnande och effektiv miljö gäller följande regler:

1. **Respekt:** Vi håller en god ton. Inga personangrepp eller diskriminering.
2. **Säkerhet först:** Ingen kod som äventyrar användares integritet eller säkerhet kommer att accepteras.
3. **Transparens:** Alla beslut fattas öppet i communityn.
4. **Kvalitet:** Vi prioriterar prestanda och resurssnålhet för att inkludera användare med äldre hårdvara.
