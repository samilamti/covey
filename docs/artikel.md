# Artikel: Varför ett medborgarinitiativ är viktigare än Facebook

I en värld där sociala medier har blivit synonyma med datainsamling och vinstoptimering, behövs ett alternativ. Här är skillnaden mellan Medborgarstöd och jättar som Facebook och LinkedIn:

### 1. Du är inte produkten
Facebook tjänar pengar på att sälja din uppmärksamhet till annonsörer. Vi tjänar inga pengar. Vårt enda mål är att du ska få hjälp eller kunna hjälpa någon annan.

### 2. Verifierad identitet kontra anonymitet/botar
Genom att använda nationellt ID (BankID) eliminerar vi trollkonton och bedrägerier. Du vet att personen du pratar med är den de utger sig för att vara.

### 3. Öppen källkod (Open Source)
Vår kod är öppen för granskning. Vem som helt kan se hur vi hanterar data. Det finns inga dolda algoritmer som styr vad du ser.

### 4. Icke-vinstdrivande foundation
Vi ägs inte av riskkapitalister. Vi styrs av våra medlemmar och vårt syfte. Syftet är social nytta, inte ekonomisk tillväxt.

---

## 👶 Enkel version (För 13-åringar)
- **Ingen reklam:** Vi säljer inte din information till företag som vill visa dig reklam.
- **Inga troll:** Eftersom alla använder BankID kan ingen gömma sig bakom fejkade namn för att vara elaka.
- **Vi äger det tillsammans:** Ingen rik gubbe i USA bestämmer över appen. Vi som använder den bestämmer.
- **Öppet för alla:** Vem som helst kan titta på hur vi har byggt appen för att se att vi inte fuskar.
