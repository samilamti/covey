Við erum að byggja opinn vettvang fyrir borgarastuðning og tæknileg hæfni er kjarni vinnu okkar. Öryggi og aðgengi eru leiðarstef okkar.

## Áherslur

### Öryggi og persónuvernd

Þar sem við samþættum við BankID og höndlum persónuupplýsingar er öryggi afar mikilvægt.

- Hjálpaðu okkur að skoða kóðann fyrir veikleikum.
- Innleiddu örugg sannvottunarferli.
- Töktu þátt í hönnun arkitektúrsins til að lágmarka gagnageymslu (privacy by design).

### Frontend og aðgengi

Forritið verður að virka á öllu frá gömlum Android-tækjum til nýjustu iPhone-síma.

- Fínstilltu afköst og minninotkun.
- Smídaðu sveigjanleg viðmót sem fylgja aðgengisstaðlum (WCAG).
- Aðstoðaðu við PWA-innleiðingu.

### Samþættingar

- BankID-samþætting (þar á meðal prófunarumhverfi).
- API-þróun fyrir framtíðar samþættingar þriðja aðila.

## Tæknistaflinn

- **Frontend**: Preact 10 + Vite + Tailwind CSS + i18next + Socket.io + Leaflet
- **Backend**: Node 22 + Express 5 + Socket.io + PostgreSQL 16 + jose (JWT)
- **Innviðir**: Docker Compose + Traefik + nginx
- **Próf**: node:test (backend), vitest (frontend)

## Byrjaðu

Frumkóðinn er á [Codeberg](https://codeberg.org/Sami-X-Lamti/Tillsammans). Klónaðu geymsluhúsið, lestu þróunarskjölunina og opnaðu fyrsta málið þitt.
