Covey-p piginnaanissartik suliaqartunik aamma ammarluinnaq koodinik suliniuteqarpoq, kisiannili akiliutigisariaqartut tøkvut attaveqarfik aaqqiissutaasumik aamma atuisoqarsinnaasumik isigalugu.

## Aningaasat sunut?

Tunisitsinerit beinleiðis rekstrunut:

1. **BankID-akiliutit** -- Aaqqiissutaasumik iserfissaq aamma nalunaarsortaasut uppernarsaanerat akiliuteqarpoq. Pingaarutigiluinnarpoq app-imut.
2. **Hosting aamma infrastruktúr** -- Serverit, domæner aamma atuinissamut 24/7.
3. **Codeberg aamma verkfør** -- Codeberg-imut tunisitsisaravit aamma CI/CD-tænastunut akiliutigisariaqarsinnaavugut.

## Qanoq ikiorsinnaanermut?

Tunisitsinissamut aaqqiissutit pilersitsinerlugit. Nalinginnaasumik ikiorsinnaavutit:

- **Swish** -- Nalinginnaasumik ataatsimut tunisitsinerit.
- **Open Collective** -- Ammarluinnarmik -- takusinnaavoq aningaasat qanoq atuineqartut.
- **Codeberg / GitHub Sponsors** -- Qaammatit tamarmik tunisitsisaravit siuarsinnaalerlutit.
