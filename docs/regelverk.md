# Regelverk för deltagande i Open Source-projektet

För att skapa en välkomnande och effektiv miljö gäller följande regler:

1. **Respekt:** Vi håller en god ton. Inga personangrepp eller diskriminering.
2. **Säkerhet först:** Ingen kod som äventyrar användares integritet eller säkerhet kommer att accepteras.
3. **Transparens:** Alla beslut fattas öppet i communityn.
4. **Kvalitet:** Vi prioriterar prestanda och resurssnålhet för att inkludera användare med äldre hårdvara.
5. **Licens:** Allt bidrag sker under [Öppen licens, t.ex. MIT eller AGPL].

---

## 👶 Enkel version (För 13-åringar)
1. **Var snäll:** Vi hjälps åt och klankar inte ner på varandra.
2. **Tänk på säkerheten:** Vi ska aldrig göra något som gör att användarnas data läcker ut.
3. **Gör det snabbt:** Appen ska fungera även på gamla mobiler som inte är superdyra.
4. **Dela med dig:** Allt vi gör ska vara gratis för andra att använda och förbättra.
