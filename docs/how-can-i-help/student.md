# Hur du kan hjälpa till som Student

Din nyfikenhet och ditt perspektiv är en stor tillgång för projektet. Oavsett om du studerar teknik, samhällsvetenskap eller juridik kan du bidra.

## Vad kan du göra?

### Examensarbete och Uppsatser
Använd plattformen som case i dina studier.
- **Teknik:** Skriv om säker arkitektur för medborgarplattformar eller prestandaoptimering för mobila webbar.
- **Sociologi/Beteendevetenskap:** Undersök hur digitala verktyg kan öka den lokala sammanhållningen och tryggheten.
- **Design:** Gör användarstudier och föreslå förbättringar i UX/UI för specifika målgrupper.

### Sprid ordet
- Prata om projektet på ditt universitet eller i din studentförening.
- Hjälp oss att nå ut till yngre målgrupper som kan behöva stöd eller vill hjälpa till.

### Översättning och Dokumentation
- Hjälp till att göra dokumentationen tydlig och pedagogisk.
- Översätt appen till fler språk för att inkludera fler medborgare i samhället.
