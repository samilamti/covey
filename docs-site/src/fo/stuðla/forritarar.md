Vit byggja eina opna skipan fyri borgarastuðul, og tøknilig vitan er kjarnin í arbeiðinum hjá okkum. Trygd og atkomugleiki eru leiðarljós okkara.

## Áherslufylki

### Trygd og privatlív

Síðani vit integrera við BankID og handfara persónaupplýsingar, er trygdin kritisk.

- Hjálp okkum at granska kóðan fyri veikleikum.
- Ger tryggar samgildingargongdir.
- Luttaka í mótgangi av bygnaðinum fyri at minka dátugoymingu (privacy by design).

### Frontend og atkomugleiki

Appin skal virka á øllum, frá gomlum Android-tólum til nýggjastu iPhones.

- Betri virki og minnisbrúk.
- Bygg svarlig rúmarflátur, sum fylgja atkomugleikastaðlum (WCAG).
- Hjálp til við PWA-innlagingina.

### Integratión

- BankID-integratión (inkl. royndarumhvørvi).
- API-menning fyri komandi triðjapartintegratión.

## Tøknistakkur

- **Frontend**: Preact 10 + Vite + Tailwind CSS + i18next + Socket.io + Leaflet
- **Backend**: Node 22 + Express 5 + Socket.io + PostgreSQL 16 + jose (JWT)
- **Infra**: Docker Compose + Traefik + nginx
- **Royndir**: node:test (backend), vitest (frontend)

## Byrja

Keldukóðin er á [GitHub](https://github.com/samilamti/covey). Klona goymslan, les forritaraskrivirnar og opna tín fyrsta mál.
