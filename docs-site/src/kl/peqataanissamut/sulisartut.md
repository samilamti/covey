Ammarluinnaq attaveqarfimik inuit ikiorsinnaassuteqarfiannik sanaavugut, aamma teknikkeqarneq suliniutip qitiusutaavoq. Aaqqiissutaasut aamma atuinissamut suliniutigivagut.

## Suliassarsiornissamik

### Aaqqiissutaasut aamma namminersorneq

BankID-imik integrerarluta aamma inuit daatat atuisakkit, aaqqiissutaasut pingaarutigiluinnarpput.

- Koodit veikleikamik misissuisigut.
- Aaqqiissutaasumik samgildinermi suliaqarsinnaavutit.
- Privacymik designeq aqqutigalugu.

### Frontend aamma atuinissamut

App tamarmik atuisoqarsinnaatitaassavoq, suliassarsiorsinnaanngitsuniit nutaanullu.

- Suliniuterit aamma minnissap atunnerit.
- Svarligit brugerflader WCAG malillugit.
- PWA-mik ikiorsinnaanermut.

### Integratión

- BankID-integratión (testumhvørvi ilanngullugu).
- API-menning siunissami integratióninut.

## Teknikkip stakki

- **Frontend**: Preact 10 + Vite + Tailwind CSS + i18next + Socket.io + Leaflet
- **Backend**: Node 22 + Express 5 + Socket.io + PostgreSQL 16 + jose (JWT)
- **Infra**: Docker Compose + Traefik + nginx
- **Testit**: node:test (backend), vitest (frontend)

## Aallartinneq

Koodit [Codeberg](https://codeberg.org/Sami-X-Lamti/Tillsammans)-imi nassiunneqarsimasut. Klonarsiguk, sulisartut skjalertallit atuarsinnaassavat aamma siullermik aammassugaq ammarsinnaallugu.
