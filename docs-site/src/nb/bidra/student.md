Din nysgjerrighet og ditt perspektiv er en stor ressurs. Uansett om du studerer teknologi, samfunnsvitenskap eller jus kan du bidra.

## Hva kan du gjore?

### Masteroppgave og avhandlinger

Bruk Covey som case i studiene dine:

- **Teknologi** -- Skriv om sikker arkitektur for innbyggerplattformer eller ytelsesoptimalisering for mobile websider.
- **Sosiologi** -- Undersok hvordan digitale verktoy kan oke lokalt samhold og trygghet.
- **Design** -- Gjennomfor brukerstudier og foresla forbedringer i UX/UI.

### Spre ordet

- Snakk om prosjektet pa universitetet ditt eller i studentforeningen.
- Hjelp oss a na ut til yngre malgrupper.

### Oversettelse og dokumentasjon

- Hjelp til a gjore dokumentasjonen tydelig og pedagogisk.
- Oversett appen til flere sprak for a inkludere flere.
