# Enkla förklaringar (För alla åldrar!)

Här förklarar vi vad projektet går ut på på ett lite enklare sätt.

## 1. Projektplanen (Kort och gott)
Vi vill bygga en app där grannar och folk i samma stad kan hjälpa varandra. Det kan handla om att låna en borrmaskin, få hjälp att bära en soffa eller bara kolla om någon behöver sällskap. 

**Det speciella:** Du loggar in med BankID så att vi vet att alla är de dom säger att de är. Det gör det tryggt för alla!

## 2. Inlägget till sociala medier
"Tänk om det fanns en app för att hjälpa varandra, där ingen försökte tjäna pengar på dig? Nu bygger vi den! Logga in säkert med BankID, slipp reklam och hjälp en granne idag. Vi gör det här tillsammans! 🌟 #HjälpEnGranne #SäkertInternet"

## 3. Varför är vi bättre än Facebook/TikTok?
- **Ingen reklam:** Vi säljer inte din information till företag som vill visa dig reklam.
- **Inga troll:** Eftersom alla använder BankID kan ingen gömma sig bakom fejkade namn för att vara elaka.
- **Vi äger det tillsammans:** Ingen rik gubbe i USA bestämmer över appen. Vi som använder den bestämmer.
- **Öppet för alla:** Vem som helst kan titta på hur vi har byggt appen för att se att vi inte fuskar.

## 4. Regler för att hjälpa till med koden
Om du vill hjälpa oss att programmera appen finns det några enkla regler:
1. **Var snäll:** Vi hjälps åt och klankar inte ner på varandra.
2. **Tänk på säkerheten:** Vi ska aldrig göra något som gör att användarnas data läcker ut.
3. **Gör det snabbt:** Appen ska fungera även på gamla mobiler som inte är superdyra.
4. **Dela med dig:** Allt vi gör ska vara gratis för andra att använda och förbättra.
