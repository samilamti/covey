Covey ведуть волонтери та відкритий код. Незалежно від вашого досвіду, є способи, якими ви можете допомогти.

## Знайдіть свій спосіб допомогти

- **[Розробники](/uk/dopomoha/rozrobnyky/)** — Аудит безпеки, фронтенд, доступність та інтеграції.
- **[Юридична](/uk/dopomoha/yurydychna/)** — GDPR, користувацькі угоди, організаційна форма та ліцензування.
- **[Студенти](/uk/dopomoha/studenty/)** — Дипломні роботи, академічні контакти та документація.
- **[Підприємці](/uk/dopomoha/pidpryyemtsi/)** — Фінансування, партнерства та побудова організації.
- **[Фінансово](/uk/dopomoha/finansovo/)** — Підтримайте утримання та розвиток.
- **[Нетехнічна](/uk/dopomoha/netekhnichna/)** — Бета-тестування, зворотний зв'язок та сарафанне радіо.
- **[Швидкі дії](/uk/dopomoha/shvydki-diyi/)** — Маєте п'ять хвилин? Можете зробити велику різницю.

## Чому варто допомагати?

Covey — це некомерційна громадянська ініціатива. Кожен внесок — чи то код, юридична порада, поширення в соціальних мережах чи пожертва — допомагає зробити повсякденне життя безпечнішим для більшої кількості людей.

## Як почати

Увесь вихідний код знаходиться на [Codeberg](https://codeberg.org/Sami-X-Lamti/Tillsammans). Відкрийте тікет, надішліть pull request або зв'яжіться з нами напряму.
