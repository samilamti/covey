Ujaassitsigisaat aamma isumaliutissaqarsinnaanersuutit pingaarutilerpput. Teknikkimik, inuiaqatigiinnut imaluunniit inatsisitigut ilinniartuugaluit ikiorsinnaavutit.

## Suliassarsiornissamik

### Ilinniarnerit aamma allatsernerit

Covey-mik atuillutit ilinniarnermi:

- **Teknik** -- Aaqqiissutaasumik designeq inuit attaveqarfiannut imaluunniit mobilinut webinnut.
- **Inuiaqatigiinnut ilisimasat** -- Stafræn verkfør qanoq inuiaqatigiinnut aaqqiissutaasumik ikiorsinnaanermut.
- **Design** -- Brugerundersøgelser aamma UX/UI-mik bøtertigut.

### Oqaluttarneq

- Universitarmi imaluunniit ilinniarfinni oqaluttarneq.
- Inuusuttut atorsinnaanermut ikiorsinnaanermut.

### Umseting aamma skjalavinna

- Skjaler tyddiligit aamma ilinniarneq.
- App-ip oqaatsitigut amerlanerusunut.
