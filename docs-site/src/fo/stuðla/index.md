Covey er opin keldukota, og ískoyti uttanífrá ger tænastuna betri. Óansæð tín bakgrund eru møguleikar at hjálpa til.

## Finn tín hátt at stuðla

- **[Forritarar](/fo/stuðla/forritarar/)** -- Trygdargransking, frontend, atkomugleiki og integratión.
- **[Løgfrøði](/fo/stuðla/løgfrøði/)** -- GDPR, brúkaraavtalur, felagsskipan og lisensspurningar.
- **[Lesandi](/fo/stuðla/lesandi/)** -- Útbúgvingaruppgávur, universitetssamband og skjalavinna.
- **[Framiløga](/fo/stuðla/framiløga/)** -- Fígging, samstarv og felagsskipan.
- **[Ikki-tekniskt](/fo/stuðla/ikki-tekniskt/)** -- Betaroyndir, tilbakameldingar og munn-til-munn.
- **[Skjót íkast](/fo/stuðla/skjót-íkast/)** -- Fimm minuttir? Ger stóra munin samavæl.

## Hví stuðla?

Covey verður rikið uttan vinningsbýti, avlop fer aftur inn í virksemið. Hvørt ískoyti, óansæð um tað er kota, løgfrøðilig ráðgeving ella ein deiling á sosialum miðlum, hjálpir til at gera gerandisdagin tryggari fyri fleiri.

## Byrja

Allur keldukóðin er á [Codeberg](https://codeberg.org/Sami-X-Lamti/Tillsammans). Opna eitt mál, send eitt pull request ella settu teg í samband beinleiðis.
