Covey drivs av frivilliga krafter och öppen källkod, men det finns fasta kostnader som är nödvändiga för att hålla plattformen säker och tillgänglig.

## Vad går pengarna till?

Dina donationer går direkt till driftkostnader:

1. **BankID-avgifter** — Säker inloggning och verifiering av användare medför transaktionskostnader. Detta är vår största utgiftspost men kritisk för appens funktion.
2. **Hosting och infrastruktur** — Servrar, domännamn och tillgänglighet dygnet runt.
3. **Codeberg och verktyg** — Vi stödjer Codeberg som plattform och kan behöva betala för CI/CD-tjänster.

## Hur du kan bidra

Vi håller på att sätta upp formella donationsvägar. Inom kort kan du stödja oss via:

- **Swish** — Snabba engångsdonationer.
- **Open Collective** — Full transparens — se exakt hur varje krona används.
- **Codeberg / GitHub Sponsors** — Månadsgivande för långsiktigt stöd.
