# LinkedIn-inlägg

**Rubrik: Dags för ett mänskligare internet? 🇸🇪🇳🇴🇩🇰**

Vi lanserar nu ett nytt initiativ: En medborgarägd plattform för grannsamverkan och stöd – helt utan vinstintresse. 

Varför? För att vi tror att trygghet börjar med att vi vet vem vi pratar med (verifierat via BankID) och att vi äger vår egen data. Inga algoritmer som vill sälja på dig saker, bara människor som vill hjälpa människor.

🚀 **Öppen källkod:** Vi bygger detta tillsammans.
🔒 **Hög integritet:** Din data är din, inte en produkt.
🤝 **Utan vinstutdelning:** Tryggheten är målet, inte utdelningen.

Vill du vara med och bygga framtidens digitala gemenskap? Läs mer i vår projektplan och häng med på resan!
