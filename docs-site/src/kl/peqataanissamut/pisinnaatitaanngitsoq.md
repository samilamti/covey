Koodimik ilisimanngilatit kisiannili assigiinngitsumik ikiorsinnaavutit. Isumaliutigisassatit tamarmillu suliassaqarfiusinnaavoq.

## Ullormut tamanut

### Betatesti aamma tilbakemelding

- App-imik atuinermi ullormut tamanut.
- Buggit imaluunniit ajornartut oqaaseqarsinnaallutit.
- Sunaassaq tørvut -- isumaliutit pitsaanerpaapput nunameersunik tørvunut.

### Binninnaq aamma ikiorsinnaanneq

- Atuisoqarsinnaanngitsut nutaat binninnaq oqaaseqarsinnaallutit.
- Ajunngitsunik imaluunniit ajortumik oqaaseqarsinnaallutit.

### Oqaluttarneq

- Nunaqqarfinni, ilaannu aamma ilaanut Covey-mik oqaluttarneq.
- Utoqqarnerpaannut imaluunniit teknikkeqarnanit ikiorsinnaanermut.
- Sosialamiutanik nassiunnermi.
