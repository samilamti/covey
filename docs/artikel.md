# Artikel: Varför en trygghetstjänst utan vinstutdelning är viktigare än Facebook

I en värld där sociala medier har blivit synonyma med datainsamling och vinstoptimering, behövs ett alternativ. Här är skillnaden mellan Covey och jättar som Facebook och LinkedIn:

### 1. Du är inte produkten
Facebook tjänar pengar på att sälja din uppmärksamhet till annonsörer. Vi tjänar inga pengar på din uppmärksamhet: ingen reklam, ingen datahandel, inga sponsrade matchningar. Vårt enda mål är att du ska få hjälp eller kunna hjälpa någon annan.

### 2. Verifierad identitet kontra anonymitet/botar
Genom att använda nationellt ID (BankID) eliminerar vi trollkonton och bedrägerier. Du vet att personen du pratar med är den de utger sig för att vara.

### 3. Öppen källkod (Open Source)
Vår kod är öppen för granskning. Vem som helt kan se hur vi hanterar data. Det finns inga dolda algoritmer som styr vad du ser.

### 4. Utan vinstutdelning
Covey drivs av Covey AB, ett svenskt aktiebolag utan vinstutdelning — överskott återinvesteras i verksamheten. Uppdraget står i bolagsordningen, koden är öppen och besluten dokumenterade.

---

## Enkelt förklarat
- **Ingen reklam:** Vi säljer inte din information till företag som vill visa dig reklam.
- **Inga troll:** Eftersom alla använder BankID kan ingen gömma sig bakom fejkade namn för att vara elaka.
- **Ingen utdelning till ägare:** Pengar som blir över går tillbaka in i tjänsten, inte till aktieutdelning. Vad appen får och inte får göra står skrivet i bolagets regler.
- **Öppet för alla:** Vem som helst kan titta på hur vi har byggt appen för att se att vi inte fuskar.
