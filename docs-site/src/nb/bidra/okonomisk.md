Covey drives av frivillig innsats og apen kildekode, men det finnes faste kostnader som er nodvendige for a holde plattformen sikker og tilgjengelig.

## Hva gar pengene til?

Donasjonene dine gar direkte til driftskostnader:

1. **BankID-avgifter** -- Sikker innlogging og verifisering av brukere medforer transaksjonskostnader. Dette er var storste utgiftspost, men kritisk for appens funksjon.
2. **Hosting og infrastruktur** -- Servere, domenenavn og tilgjengelighet dognet rundt.
3. **Codeberg og verktoy** -- Vi stotter Codeberg som plattform og kan trenge a betale for CI/CD-tjenester.

## Hvordan du kan bidra

Vi holder pa a sette opp formelle donasjonskanaler. Snart kan du stotte oss via:

- **Vipps** -- Raske engangsdonasjoner.
- **Open Collective** -- Full transparens -- se noyaktig hvordan hver krone brukes.
- **Codeberg / GitHub Sponsors** -- Manedlig stotte for langsiktig bidrag.
