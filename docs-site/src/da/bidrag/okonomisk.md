Covey drives af frivillig indsats og aben kildekode, men der er faste omkostninger, som er nodvendige for at holde platformen sikker og tilgaengelig.

## Hvad gar pengene til?

Dine donationer gar direkte til driftsomkostninger:

1. **BankID-gebyrer** -- Sikker login og verificering af brugere medforer transaktionsomkostninger. Dette er vores storste udgiftspost, men kritisk for appens funktion.
2. **Hosting og infrastruktur** -- Servere, domaenenavne og tilgaengelighed dognet rundt.
3. **Codeberg og vaerktoejer** -- Vi stotter Codeberg som platform og kan have behov for at betale for CI/CD-tjenester.

## Hvordan du kan bidrage

Vi er i gang med at opsaette formelle donationskanaler. Snart kan du stotte os via:

- **MobilePay** -- Hurtige engangsdonationer.
- **Open Collective** -- Fuld transparens -- se praecis, hvordan hver krone bruges.
- **Codeberg / GitHub Sponsors** -- Manedligt bidrag til langsigtet stotte.
