نبني منصة مفتوحة لدعم المواطنين، والكفاءة التقنية هي جوهر عملنا. الأمان وإمكانية الوصول هما شعارنا.

## مجالات التركيز

### الأمان والخصوصية

بما أننا نتكامل مع BankID ونعالج بيانات شخصية، فالأمان أمر حاسم.

- ساعدنا في مراجعة الكود بحثاً عن الثغرات.
- نفّذ مسارات توثيق آمنة.
- شارك في تصميم البنية لتقليل تخزين البيانات (الخصوصية حسب التصميم).

### الواجهة الأمامية وإمكانية الوصول

يجب أن يعمل التطبيق على كل شيء من أجهزة Android القديمة إلى أحدث هواتف iPhone.

- حسّن الأداء واستخدام الذاكرة.
- ابنِ واجهات متجاوبة تتبع معايير إمكانية الوصول (WCAG).
- ساعد في تنفيذ PWA.

### التكاملات

- تكامل BankID (بما في ذلك بيئات الاختبار).
- تطوير API لتكاملات مستقبلية مع أطراف ثالثة.

## المجموعة التقنية

- **الواجهة الأمامية**: Preact 10 + Vite + Tailwind CSS + i18next + Socket.io + Leaflet
- **الواجهة الخلفية**: Node 22 + Express 5 + Socket.io + PostgreSQL 16 + jose (JWT)
- **البنية التحتية**: Docker Compose + Traefik + nginx
- **الاختبارات**: node:test (خلفية)، vitest (أمامية)

## ابدأ الآن

الشيفرة المصدرية متاحة على [GitHub](https://github.com/samilamti/covey). انسخ المستودع، اقرأ وثائق المطورين، وافتح أول بلاغ لك.
