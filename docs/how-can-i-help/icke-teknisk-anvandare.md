# Hur du kan hjälpa till som Icke-teknisk användare

Du behöver inte kunna koda för att göra skillnad. Faktum är att din input är avgörande för att vi ska bygga något som fungerar för *alla*, inte bara tekniker.

## Bidra i vardagen

### Betatesta och Ge Feedback
- Använd appen i din vardag.
- Rapportera buggar eller saker som är krångliga att förstå.
- Berätta vad du saknar – de bästa idéerna kommer från verkliga behov.

### Community och Moderering
- Var en god förebild i dina lokala grupper.
- Hjälp till att välkomna nya användare.
- Rapportera olämpligt innehåll för att hålla plattformen trygg.

### Sprid budskapet
- Berätta för grannar, vänner och släktingar om Covey.
- Hjälp äldre eller mindre teknikvana personer i din närhet att komma igång.
- Dela våra inlägg i sociala medier.
