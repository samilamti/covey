Covey ammasumik kildekodeqarpoq, akitsuutillu avataaneersut sullissinermik pitsanngorsaapput. Tunuliaqutit apeqqutaatillugit, ikiuussinnaaneqarput.

## Qanoq ilaasortaasinnaassut nassaruk

- **[Sulisartut](/kl/peqataanissamut/sulisartut/)** -- Aaqqiissutaasumik misissuineq, frontend, atuinissamut aamma integratión.
- **[Inatsisit](/kl/peqataanissamut/inatsisit/)** -- GDPR, atuisoqarsinnaanngitsut avtalit, organisationit aamma lisensit.
- **[Atuartut](/kl/peqataanissamut/atuartut/)** -- Ilinniarnerit, universitetinut attavigineq aamma skjalavinna.
- **[Pisiniarfissaq](/kl/peqataanissamut/pisiniarfissaq/)** -- Aningaasarsiorneq, samstarv aamma organisationinut.
- **[Pisinnaatitaanngitsoq](/kl/peqataanissamut/pisinnaatitaanngitsoq/)** -- Betatestineq, tilbakemelding aamma oqaloqateqarneq.
- **[Sukkasuumik](/kl/peqataanissamut/sukkasuumik/)** -- 5 minutsi? Assut ikiorsinnaavutit.

## Sooq ilaasortaassut?

Covey kingunertanik agguaassinatik ingerlanneqarpoq, sinneqartoorutillu ingerlatamut utertinneqartarput. Akitsuutit tamarmik, imeqqa kode-q, inatsisitigut siunnersuineq imaluunniit sociale mediennut agguaassinneq, ulluinnarni toqqissisimanerungaartitsiniartarput amerlanerpaamut.

## Aallartinneq

Koodit tamarmik [GitHub](https://github.com/samilamti/covey)-imi. Aammassugaq ammaruk, pull request-imik nassiuk imaluunniit attavigisigut.
